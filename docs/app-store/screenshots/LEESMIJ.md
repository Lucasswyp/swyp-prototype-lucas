# Schermafbeeldingen voor de App Store (6,9 inch, 1320 x 2868)

- `met-kop/`: de set om te uploaden (met logo en een kop boven elk scherm).
- de losse `01-` tot `05-` bestanden: dezelfde schermen zonder kop.

Genomen van swyp.it op 3 november 2026 met de echte video's van Lucas Bedrijf, zonder inloggen: feed, bedrijfsprofiel, zoeken met voorstellen, zoekresultaten en rewards. Berichten, Wallet en Profiel vragen een inlog; neem die op met je demo-account als je ze erbij wilt. Alleen iPhone: geen iPad-schermen nodig.
